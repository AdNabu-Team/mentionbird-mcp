# Brief template and citability principles

Industry-neutral. Square brackets mark the parts that change per business.

## What makes a page get cited, in order of impact

AI assistants cite pages they can extract clear, specific, attributable claims from, and they
favor sources others already treat as authoritative.

1. **Mentions on sites you don't own.** This is the biggest lever and it's off-page (the listicle
   actions in the plan). The brief should say so when third-party pages dominate the
   citations.
2. **Named attribution.** A claim from a named person with a stated role is more quotable than
   anonymous marketing copy. Put a name and a credential on opinions.
3. **Specific numbers.** A concrete figure ("[number] [unit] in [timeframe]") gets cited; an
   adjective ("fast", "best-in-class") doesn't. Original data is strongest, because it makes the
   page the only possible source.
4. **The answer first.** Put the answer in the first two sentences of each section. Headings
   that match real questions, tables, short lists and FAQ-style blocks isolate answers into
   chunks an assistant can lift.
5. **Freshness**, where the category changes: a visible last-updated date and current details.
6. **Consistent naming.** Describe the brand and what it offers the same way everywhere.

Overrated: schema markup (worth having, but no measured citation lift), keyword density
(stuffing lowers citation odds), and publishing volume (one page with a real number beats ten thin
ones).

## Brief template

```
# Brief: <working title, with the year if the AI's searches use it>

Mode: Measured (MentionBird, <start> to <end>) | Estimated
Target question: <the buying question, as a customer would ask it>
Also covers: <2–5 related questions or the AI's own search strings>
Action: Improve <URL> | Create new page (and link it from <URL>)
Page type: <listicle / comparison / how-to with a recommendation / offering page>, because
<what gets cited now>

## Why this page, in numbers (Measured mode)
- Answers naming any brand: N% | naming us: N% | answers citing the web: N%
- Brands recommended instead: <top 3 from the leaderboard>
- Answers that skip searching: N% (if high: off-page matters more than this page)

## Where the brand already appears
<pages read that already list the brand, and its position; "nowhere" is a finding too>

## Searches to cover
<the strings the AI searched for, or the keyword variants from web research, grouped into the
headings they map to>

## Opening (answer first)
<the two sentences that directly answer the target question; if the term is ambiguous, the first
sentence says which meaning the page covers>

## Sections
<one heading per decision criterion the AI uses, each with: the question it answers, the claim
to make, and the proof to attach>

## Proof to include
- Numbers: <what, and the source; placeholders if the user must supply them>
- Named expert: <who, with what credential, saying what>
- Comparison table: <columns = the AI's decision criteria; rows = the brands it recommends,
  including the user's>
- Original data, if any: <survey, benchmark, records only the user has>

## What the cited pages do that this page must match or beat
<3–5 bullets from the cited pages: structure, depth, data, freshness>

## Placeholders the user must fill
<every [stat], [quote] or [example] left in the brief>

## Off-page note (when relevant)
<third-party pages that dominate citations for this question → listicle actions in the plan>
```
